# my-fitness: notes for Claude

Single-user gym tracker: Nuxt 4 SPA + Nitro API, SQLite via Drizzle, Nuxt UI. Setup, commands and architecture are in `DEVELOPMENT.md`; read it only for the part you need.

## Rules

- **English everywhere in code and tests:** identifiers, DB columns, API fields, file names, and exercise names in tests and fixtures (e.g. "Plank", not "Deska"). Polish appears only in the trainer's PDF header labels (`PLAN_HEADER_LABELS` in `shared/plan-import.ts`) and the synthetic PDF's header row. Users' own exercise names stay as they type or import them; no translation.
- **No real data in the repository:** no real plans or PDFs, no real names, no real video links. Use made-up values and `https://example.com/...` links. The test plan PDF is generated by `scripts/make-plan-fixture-pdf.mjs`. A file the user shares (e.g. their own plan) is read for understanding only and never copied into tracked files.
- `npm run hygiene` enforces both rules (also as the pre-commit hook and in CI).

## Checks (keep logs out of the conversation)

- Prefer the `verifier` sub-agent for checks; it reports failures only.
- `npm run verify`: hygiene, lint, typecheck, build, unit + API tests, one line per step. Add `-- --e2e` for the E2E suite.
- `npm run test:e2e:local [-- <file> -g "<name>"]`: E2E against the production build with a throwaway DB and test credentials; never uses `.env` or `./data`.
- API tests run against `.output`: build first after server changes.
- Windows: a running app server locks `.output`, so `npm run build` fails; stop it first.

## Workflow

- Changes go through OpenSpec: `/opsx:explore` → `/opsx:propose` → `/opsx:apply` → `/opsx:archive`. State lives in `openspec/`, so `/clear` between phases is safe.
- During `/opsx:apply`, run the `diff-reviewer` sub-agent after each task group, and `verifier` before marking a group done.
- Prefer the Edit tool for multi-line edits; shell heredocs with quotes break in Git Bash.
- Schema change: edit `server/db/schema.ts`, then `npm run db:generate`; commit the migration.
